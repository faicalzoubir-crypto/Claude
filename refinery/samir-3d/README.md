# مصفاة لاسامير — نموذج ثلاثي الأبعاد

نموذج تفاعلي (three.js) لمصفاة لاسامير بالمحمدية، مع شرح مراحل تكرير النفط الخام بالعربية.

- `samir-refinery.html` : مصدر الصفحة (مقطع HTML يُنشر كـ Artifact).
- `index.html` : نسخة مستقلة تُفتح مباشرة في المتصفح (تحتاج اتصالًا بالإنترنت لتحميل three.js والخطوط).

النموذج تمثيلي: مبني على الصورة وعلى التصميم المعتاد لمصفاة تحويل، وليس مخطط الموقع الحقيقي.
لإعادة توليد `index.html` بعد تعديل المصدر، يكفي تغليف `samir-refinery.html` داخل `<!doctype html><html><head><meta charset="utf-8">…</head><body>…</body></html>`.
